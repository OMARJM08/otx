# OTX ELIXIR — سيرفر حقيقي مع قاعدة بيانات

هذا مشروع Node.js + Express كامل، مع قاعدة بيانات SQLite حقيقية (ملف `.db` على القرص)،
وليس مجرد صفحة HTML. يشمل:

- **API حقيقي** لإدارة المنتجات (`/api/products`) بعمليات إضافة/تعديل/حذف
- **قاعدة بيانات SQLite** فعلية (جدول `products` و `settings`) تُنشأ تلقائياً أول تشغيل
- **تسجيل دخول أدمن** محمي بكلمة مرور مشفّرة (bcrypt) وجلسة (JWT) — وليس كلمة مرور ظاهرة في الكود
- **رفع ملفات PDF وصور حقيقي** يُخزَّن على السيرفر ويُعرض للعملاء
- **متجر عام** (`/`) يعرض المنتجات من قاعدة البيانات مباشرة
- **لوحة تحكم** (`/admin.html`) لإدارة كل شيء
- **سجل طلبات حقيقي**: كل مرة يضغط عميل "اطلب عبر واتساب"، يُسجَّل الطلب في قاعدة
  البيانات أولاً (تقدر تتابعه وتغيّر حالته من لوحة التحكم: جديد / تم التواصل / مكتمل / ملغي)
  قبل ما يفتحله واتساب
- **حماية أساسية**: Helmet (رؤوس أمان HTTP) + تحديد عدد المحاولات على تسجيل الدخول والـ API
  لمنع محاولات الاختراق الآلية

⚠️ **ملاحظة مهمة**: لا أستطيع تشغيل أو استضافة سيرفر يعمل بشكل دائم ومباشر على
الإنترنت من داخل هذه المحادثة (لا يوجد اتصال إنترنت خارجي متاح لي هنا). لكن هذا
المشروع جاهز بالكامل ليعمل على أي استضافة حقيقية خلال دقائق — الخطوات بالأسفل.

---

## 1) التشغيل محلياً على جهازك (للتجربة)

```bash
cd otx-server
npm install
cp .env.example .env
# افتح .env وعدّل: ADMIN_EMAIL / ADMIN_PASSWORD / JWT_SECRET / WHATSAPP_NUMBER
npm start
```

ثم افتح:
- المتجر: http://localhost:3000
- لوحة التحكم: http://localhost:3000/admin.html

---

## 2) رفعه على سيرفر حقيقي مجاناً (Render.com) — الأسهل

**طريقة سريعة (Blueprint جاهز):**
المشروع يحتوي ملف `render.yaml` جاهز، يعرّف كل الإعدادات والقرص الدائم تلقائياً.
1. ارفع المشروع إلى مستودع GitHub
2. من Render: **New → Blueprint** → اختر الريبو → Render يقرأ `render.yaml` تلقائياً
3. سيطلب منك تعبئة: `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `WHATSAPP_NUMBER` فقط
   (`JWT_SECRET` يُنشأ تلقائياً و `DATA_DIR` مضبوط مسبقاً على القرص الدائم)
4. اضغط Apply — بعد دقائق موقعك جاهز على رابط مثل `https://otx-elixir.onrender.com`

**أو يدوياً:**
1. أنشئ حساب مجاني على https://render.com
2. ارفع مجلد المشروع إلى GitHub
3. من لوحة Render: **New → Web Service** → اختر الريبو
4. الإعدادات:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
5. أضف Environment Variables (من تبويب Environment) بنفس أسماء `.env.example`
6. **مهم لحفظ قاعدة البيانات بشكل دائم**: من تبويب **Disks** أضف قرص (Persistent Disk)
   واربطه بمسار `/data`، ثم أضف متغير بيئة: `DATA_DIR=/data`
   (بدون هذه الخطوة، قاعدة البيانات والملفات المرفوعة قد تُمسح عند كل نشر جديد)
7. اضغط Deploy

## 3) بدائل أخرى للاستضافة
- **Railway.app** — نفس الفكرة، دعم ممتاز لـ SQLite مع Volumes
- **Fly.io** — يحتاج قليل من إعداد CLI لكنه سريع ومجاني للمشاريع الصغيرة
- **VPS خاص** (Hostinger, DigitalOcean) — أعلى تحكم، يحتاج تثبيت Node.js يدوياً

## هيكل المشروع

```
otx-server/
  server.js          نقطة تشغيل السيرفر
  db.js              إعداد قاعدة بيانات SQLite + البيانات الأولية
  routes/
    products.js      عمليات المنتجات (CRUD) + رفع PDF/صور
    admin.js          تسجيل الدخول + إعدادات الواتساب
  middleware/auth.js  التحقق من صلاحية الأدمن (JWT)
  public/            الواجهة (المتجر + لوحة التحكم)
  data/              (يُنشأ تلقائياً) قاعدة البيانات والملفات المرفوعة
```

## الأمان
- كلمة مرور الأدمن مشفّرة بـ bcrypt ولا تُخزَّن كنص صريح
- كل عمليات الإضافة/التعديل/الحذف تتطلب توكن JWT صالح
- غيّر `JWT_SECRET` في `.env` إلى قيمة عشوائية طويلة قبل النشر الفعلي
